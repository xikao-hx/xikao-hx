## About me

> Embedded Linux learner, RISC-V enthusiast, and systems explorer.

🔭 Working close to the hardware—from boot flows and kernel drivers to inter-core communication.<br />
🌱 Currently exploring Linux + RTOS AMP systems on the StarFive VisionFive 2.<br />
⚙️ Interested in small, understandable systems and the details hidden below abstractions.

## Current focus

| Area | What I am exploring |
| :--- | :--- |
| **Embedded Linux** | Kernel, device tree, drivers, Buildroot and board bring-up |
| **RISC-V & AMP** | OpenSBI, U-Boot, Linux/RTOS resource isolation and inter-core mailbox |
| **Operating systems** | Kernel internals, xv6 and the boundary between software and hardware |
| **Reliable updates** | Boot-chain integration, A/B partitions and OTA workflows |
